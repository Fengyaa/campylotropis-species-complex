## Definition of the new summary

The final configurations are **MY1–CYU–CPO** and **CY32–CPO–CYU**. MY1/CY32 are separated from their respective pooled groups. Both configurations contain the same 139 individuals, including XB_DR_C and xubo1407 as outgroups. BM31 is absent; Gln2014-8-1A and Gln2014-8-2A are CPO. The exact pooled subsets are determined by the SETS files, not by the complete species assignments in other analyses.

Native windows contain 50 usable SNPs, moving by 25 SNPs. Estimates satisfying 0 < f_d < 1 are assigned by their **start coordinate** to the same chromosome's **1-based inclusive** 10-kb interval. Estimates within each configuration/interval are averaged; available configuration means are then averaged with equal weight. This is a conditional descriptive summary of SNP-window estimates, not a recalculation from site-pattern sums within fixed 10-kb intervals, an overall introgression fraction, or a direction estimate. Native windows may span more than one interval. Negative, zero, >=1 and nonfinite estimates are excluded under the retained filtering rule; missing values are not replaced by zero.

For compatibility with existing analysis scripts, `species_trio_fd_recomputed` now stores this **two-reference summary**, rather than the superseded Cma–Cyu–Cpo result. `fd_MY1_CYU_CPO`, `fd_CY32_CPO_CYU`, raw support counts, `n_species_fd_contrasts` and `species_fd_common_support` preserve the component information. The old trio file and legacy result are excluded from the public package; a separate local backup preserves previous material.

Unused historical f_d columns have also been omitted from the window table to avoid confusing them with the final estimates. `Mean_f_d_sym_2026` remains the unchanged final sympatric summary. This update does not alter the pre-existing PSMC script or unrelated analyses.

## Updated findings

- Species-reference high-f_d NBS density is 3.01–5.50 times background, versus 4.85–6.44 times in the unchanged sympatric comparisons.
- Species-reference ADP-binding enrichment is significant at 10%, 5% and 2.5%, but not 1% (FDR=0.3994). Signal transduction is significant at 10% and 5%.
- All ADP-binding-annotated genes in the eight main high-f_d candidate sets are putative NBS genes. Table S9 retains unique counts and the corresponding GO test-family FDR.
- The main GEA species-reference f_d comparison remains nonsignificant (BH-adjusted P=0.7331). Candidate inputs remain 2,739 intervals, of which 2,651 match the parameter grid; 2,417 have eligible species-reference f_d.
- The two configurations have Spearman rho=0.1248 across 30,778 shared eligible intervals. Reference sensitivity tables are retained; overlapping signals do not constitute independent replication.

Coverage/NBS backgrounds exclude selected windows; GO universes include annotated genes in all eligible windows. Gene selection requires at least 1 bp of full gene-body overlap and uses nonredundant IDs. The 10–500-gene GO test family includes zero-hit terms in BH correction. Feature intervals use 2,000 chromosome-stratified block-bootstrap replicates at 1 Mb and 5 Mb. GEA uses 9,999 chromosome-wise circular shifts and 1,000 block-bootstrap replicates; its original 22-test BH family is retained. The additional three reference checks are a separate exploratory family.

## Independent commands

All commands may be run from any working directory by pointing to the script in the repository. Output paths are resolved relative to the repository. The following is an analysis order, not a new universal reproduction framework:

```bash
python scripts/prepare_species_fd.py
Rscript scripts/window_features.R
Rscript scripts/reference_features.R
python scripts/table_s9.py
Rscript scripts/gea_window_statistics.R
Rscript scripts/gea_reference.R
Rscript scripts/plot_genomic_landscapes.R
Rscript scripts/plot_window_features.R
python scripts/assemble_figure3.py
Rscript scripts/plot_local_genomic_landscape.R
Rscript scripts/plot_gea_window_statistics.R
```

Short checks: `prepare_species_fd.py` regenerates window summaries; `table_s9.py` exports overlap tables directly from bundled enrichment hit IDs without requiring the long enrichment analysis to run first. Full statistical reruns take longer. No original VCF is needed for these downstream analyses. Python dependencies are numpy, pandas and pypdf; the added R scripts use data.table, clusterProfiler and ggplot2. No Codex-specific runtime or artifact-tool is required. The retained XLSX is a convenience export; TSVs are the authoritative script outputs.

The added figures' final PDF/PNG exports are omitted from this public package to keep it focused on scripts, necessary inputs and compact numerical results. The plotting scripts generate them; the separately delivered manuscript figures remain available in the local analysis directory.

The species-reference update does not supply a new genome-wide D/Z test or establish the origin of allele sharing at individual loci. Local mapping and annotation limitations remain relevant to biological interpretation.
