# Analysis guide

Run the examples from the repository root. Scripts use repository-relative paths unless input arguments are required; outputs are written to `results/` or a specified output directory. Individual analyses can be run separately.

## Population structure and phylogeny

```bash
bash scripts/admixture.sh INPUT.vcf.gz INTERGENIC.pos OUTDIR
Rscript scripts/plot_admixture.R
```

The ADMIXTURE command script filters at MAF 0.01, call rate 0.90 and minimum spacing 1 kb, and performs one cross-validation-enabled fit per K. The plotting script uses the included K = 2–8 matrices; K = 1–20 matrices and the ancestry PDF are also provided. Stochastic fits may differ from the archived Q values. Cross-validation logs are generated by the command script and are not included with the archived matrices.

Convert the fourfold-degenerate, 500-bp-thinned VCF to NEXUS using `convert_vcf_to_nexus.rb` from the [species-tree tutorial](https://github.com/millanek/tutorials/tree/master/bayesian_species_tree_inference), then run:

```bash
python scripts/prepare_svd_input.py input.nex numbered.nex
```

Inspect the exported sample-number mapping before using `scripts/svdquartets.nex` in PAUP*. The helper checks 259 taxa and the outgroup positions; population partitions require the documented sample order. The conversion program and full alignment are external inputs.

## Demography

```bash
bash scripts/psmc.sh SAMPLE_LIST REF.fa GVCF_DIR VCF2FQ.py PSMC_DIR OUTDIR
python scripts/summarize_fsc.py
```

The PSMC script runs GATK → vcf2fq → fq2psmcfa → PSMC and plots the results. It requires GATK, Python, Perl, [PSMC](https://github.com/lh3/psmc), a sample list, per-individual gVCFs, the reference sequence and the compatible `vcf2fq.py` converter. Samples run sequentially; GATK is allocated 28 GB of memory. Plotting uses μ = 7 × 10⁻⁹ per site per generation and a generation time of 2 years.

The fastsimcoal2 summary script reads six models from `data/demography/fsc/`, including TPL/EST files, likelihoods and AIC. Parameter estimates and 95% bootstrap summaries are included. Identical observed spectra are stored once, with filename mappings for their model inputs.

## Genomic windows and introgression

`scripts/dsuite.sh` is a parameterized command template for [Dsuite](https://github.com/millanek/Dsuite). Supply a VCF, SETS file, rooted tree and trio definitions with matching names. Dinvestigate uses `-w 50,25`. `scripts/species_dinvestigate.sh` runs the two species-reference configurations with the included SETS/trio files and an external VCF.

The bundled 10-kb table contains diversity, differentiation, divergence, XP-CLR and fd summaries. Full genotype inputs and upstream popgenWindows/XP-CLR runs are external to the repository. The [Introgression guide](INTROGRESSION.md) describes window assignment, configuration averaging, Table S9, reference sensitivity and plotting commands.

`Rscript scripts/window_features.R` calculates threshold-specific coverage, NBS density and GO/KEGG enrichment. Dependencies include data.table, R.utils, clusterProfiler and ggplot2. Plot with `plot_window_features.R` and `plot_genomic_landscapes.R`. Putative NBS IDs are annotation outputs; the full source BLAST/UniProt inputs are external.

## Morphology and genotype–environment associations

`Rscript scripts/morphology_rda_pca.R` uses vegan to calculate morphological RDA and PCA and checks that individual climatic values match the population table. Outputs include individual-level and population-mean morphological PCA summaries and environmental PCA summaries.

For each chromosome dosage file:

```bash
mkdir -p results/prda
Rscript scripts/genomic_prda.R chromosome.raw data/climate/all_indv_env.corrected.tsv --pcs 3 --axes 6 --id-column IID --out-prefix results/prda/chr1
```

The script exports candidate sets at 3.5 and 4.0 loading standard deviations. The manuscript candidate set uses 3.5 SD and |r| >0.5. `python scripts/gea_overlap.py` identifies shared pRDA/BayPass windows; `Rscript scripts/gea_window_statistics.R` compares their genomic statistics with the background.

`scripts/baypass.sh` provides an auxiliary-model command template. Supply the full filtered SNP count file, climatic PC matrix, covariance matrix and population count, maintaining consistent population order. The association scan uses all filtered genome-wide SNPs; the covariance-estimation panel consists of 204,672 intergenic SNPs. The climatic source dataset is shared with RDA. Candidates require BF >20 decibans and per-covariate upper-tail rank probability <0.001.

## GWAS, ancestry and candidate region

`scripts/gemma.sh` provides a command template for a relatedness matrix and genetic PC1–PC3 covariates. Supply matched BED/BIM/FAM files, kinship, a numeric phenotype matrix and no-header covariates comprising an intercept and the genetic PCs. The included phenotype/FAM panel has 210 rows; missing phenotypes are excluded separately for each trait, leaving 195 individuals for glandular-hair presence. Convert the labeled phenotype TSV to GEMMA's numeric input format before running. See the [GEMMA manual](https://github.com/genetics-statistics/GEMMA/blob/master/doc/manual.tex).

`process_gemma.R` applies genome-wide corrections to all chromosome association files; `plot_gemma.R` plots the full test outputs. Both scripts print their argument usage. Significant and regional glandular-hair results are included; full scans require external association outputs.

`Rscript scripts/hybrid_ancestry.R` estimates ancestry and interclass heterozygosity from the selected-marker matrices and reference panels. `plot_hybrid_ancestry.R` visualizes these estimates. Simulated hybrid classes provide reference distributions, rather than definitive pedigree assignments.

For local genetic affinity:

```bash
python scripts/local_affinity.py
python scripts/local_affinity_sensitivity.py
Rscript scripts/plot_local_affinity.R
```

Quality-masked chromosome 8/6 genotype caches, reference order and qualification flags are included. `plot_chr8_candidate.R` and `plot_MYB_domains.R` use regional association and protein data. The source VCFs are external.

## Spatial relationships

Run `Rscript scripts/mantel.R`, followed by `Rscript scripts/mmrr.R`. Inputs include diploid Weir–Cockerham FST matrices, geographic/environmental distances and population subsets. Genetic distances are linearized as FST/(1−FST); analyses use 9,999 permutations. Dependencies include vegan and the bundled PopGenReport `lgrMMRR` function with its license notices.

## Software and outputs

[software_versions.tsv](software_versions.tsv) records software versions associated with the analyses. Additional R session information is included alongside the corresponding results. These records describe software versions rather than provide a locked environment. Genomic enrichment, permutation and bootstrap calculations may require substantial computation; many summary and plotting scripts can instead use the included processed results.
