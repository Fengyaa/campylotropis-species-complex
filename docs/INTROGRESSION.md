## Window summary definition

The configurations are **MY1–CYU–CPO** and **CY32–CPO–CYU**. MY1/CY32 are separated from their respective pooled groups. Both configurations contain the same 139 individuals, including XB_DR_C and xubo1407 as outgroups. BM31 is absent; Gln2014-8-1A and Gln2014-8-2A are CPO. The exact pooled subsets are determined by the SETS files, not by the complete species assignments in other analyses.

Native windows contain 50 usable SNPs, moving by 25 SNPs. Estimates satisfying 0 < f_d < 1 are assigned by their **start coordinate** to the same chromosome's **1-based inclusive** 10-kb interval. Estimates within each configuration/interval are averaged; available configuration means are then averaged with equal weight. This is a conditional descriptive summary of SNP-window estimates, not a recalculation from site-pattern sums within fixed 10-kb intervals, an overall introgression fraction, or a direction estimate. Native windows may span more than one interval. Negative, zero, >=1 and nonfinite estimates are excluded under the retained filtering rule; missing values are not replaced by zero.

The field `species_trio_fd_recomputed` stores the two-reference summary. `fd_MY1_CYU_CPO` and `fd_CY32_CPO_CYU` store configuration-specific estimates; support counts, `n_species_fd_contrasts` and `species_fd_common_support` identify the available contributing estimates. `Mean_f_d_sym_2026` stores the sympatric summary.

## Results overview

- Species-reference high-f_d NBS density is 3.01–5.50 times background, versus 4.85–6.44 times in the sympatric comparisons.
- Species-reference ADP-binding enrichment is significant at 10%, 5% and 2.5%, but not 1% (FDR=0.3994). Signal transduction is significant at 10% and 5%.
- All ADP-binding-annotated genes in the eight main high-f_d candidate sets are putative NBS genes. Table S9 retains unique counts and the corresponding GO test-family FDR.
- The main GEA species-reference f_d comparison is nonsignificant (BH-adjusted P=0.7331). Candidate inputs comprise 2,739 intervals, of which 2,651 match the parameter grid; 2,417 have eligible species-reference f_d.
- The two configurations have Spearman rho=0.1248 across 30,778 shared eligible intervals. Reference sensitivity tables are retained; overlapping signals do not constitute independent replication.

Coverage/NBS backgrounds exclude selected windows; GO universes include annotated genes in all eligible windows. Gene selection requires at least 1 bp of full gene-body overlap and uses nonredundant IDs. The 10–500-gene GO test family includes zero-hit terms in BH correction. Feature intervals use 2,000 chromosome-stratified block-bootstrap replicates at 1 Mb and 5 Mb. GEA uses 9,999 chromosome-wise circular shifts and 1,000 block-bootstrap replicates; BH correction spans the 22 main comparisons. The additional three reference checks are a separate exploratory family.

## Running the analyses

Run the following from the repository root. Output paths are resolved relative to the repository.

```bash
python scripts/prepare_species_fd.py
Rscript scripts/window_features.R
Rscript scripts/reference_features.R
python scripts/table_s9.py
Rscript scripts/gea_window_statistics.R
Rscript scripts/gea_reference.R
Rscript scripts/plot_genomic_landscapes.R
Rscript scripts/plot_window_features.R
python scripts/assemble_figure3.py
Rscript scripts/plot_local_genomic_landscape.R
Rscript scripts/plot_gea_window_statistics.R
```

`prepare_species_fd.py` regenerates window summaries; `table_s9.py` exports overlap tables directly from bundled enrichment hit IDs without requiring the long enrichment analysis to run first. Full statistical reruns take longer. No original VCF is needed for these downstream analyses. Python dependencies are numpy, pandas and pypdf; the R scripts use data.table, clusterProfiler and ggplot2.

Figure scripts generate PDF/PNG outputs from the included processed data. Numerical results are provided as TSV files; the XLSX file is a convenience export.

Local fd summarizes allele sharing; it does not establish its evolutionary origin at individual loci. Reference choice, mapping quality and annotation quality should be considered when interpreting local patterns.
