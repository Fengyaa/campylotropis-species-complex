# Data and Code Availability

The reference genome and associated raw sequencing data were submitted to the China National GeneBank DataBase (CNGBdb) under project accession **CNP0005557**. Whole-genome resequencing data generated in this study were deposited under **CNP0007152**.

The local project contains analysis scripts and selected processed data supporting the manuscript. It has not yet been deposited on GitHub. Add the real repository URL and optional version-specific archival DOI after publication. Describe the contents as “analysis scripts and processed data,” without claiming complete reproduction from raw reads.

Raw reads, BAMs, full VCF/PLINK datasets, full genome-wide association outputs and climate raster databases are intentionally external. The archive retains compact analysis inputs, candidate tables and selected results.

The archive also includes the final MY1–CYU–CPO and CY32–CPO–CYU local f_d outputs and group definitions, downstream window summaries, reference sensitivity analyses, GO/NBS overlap scripts and selected figure inputs/results. These processed inputs support the added methods and results without requiring complete reproduction of the study.
