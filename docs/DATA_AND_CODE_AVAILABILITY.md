# Data and Code Availability

The reference genome and associated raw sequencing data have been deposited in the China National GeneBank DataBase (CNGBdb) under project accession **CNP0005557**. Whole-genome resequencing data generated in this study have been deposited under **CNP0007152**.

Analysis scripts and supporting processed data are available at [https://github.com/Fengyaa/campylotropis-species-complex](https://github.com/Fengyaa/campylotropis-species-complex). The repository includes morphological measurements, climatic data, sample metadata, demographic model files, processed genomic inputs, candidate tables and selected results.

The Dsuite inputs include the MY1–CYU–CPO and CY32–CPO–CYU local-window outputs and sample-group definitions. These support downstream window summaries, reference-sensitivity analyses, GO/NBS overlap tables and figure generation.

Raw reads, alignment files, full VCF/PLINK datasets, full genome-wide association outputs and climatic raster databases are external to this repository. Requirements for individual analyses are described in the [Analysis guide](ANALYSIS_GUIDE.md).
